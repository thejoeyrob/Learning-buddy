# Nova Math Studio — Grade 5 Home Learning

A new, independent single-player home-learning PWA. It is not a replacement for Shrubbery Showdown and contains none of that app's content.

## Curriculum scope
The question system is aligned only to the five standards in the supplied Grade 5 ILEARN-style practice curriculum:
- 5.M.4 — volume using unit cubes, layers and multiplication
- 5.M.5 — V = l × w × h and V = B × h
- 5.NS.1 — compare/order fractions, mixed numbers and decimals to thousandths
- 5.CA.1 — whole-number division with up to four-digit dividends and two-digit divisors
- 5.CA.2 — contextual multiplication/division and interpreting remainders

## Included
- 2,500 generated and checked practice questions (500 per standard)
- adaptive mixed lessons that bias toward weaker standards
- focused practice by standard
- mistake-review queue
- worked hints and explanations
- five mini-lessons
- drawing scratchpad
- optional device read-aloud
- local progress, streak and parent/teacher summary
- CSV progress export
- installable/offline PWA
- original mascot: Ms. Nova
- no login, multiplayer, teams, leaderboard or online dependency

## Deploy
Upload every file in this folder to the root of a static host such as GitHub Pages, Vercel, Netlify, Cloudflare Pages or any ordinary HTTPS web server. Do not put the files inside an extra nested folder unless your host is configured to serve that folder as the site root.

The service worker requires HTTPS (localhost is also permitted for development).
